# dhcp-telnet-p
DHCP Configuration Project in Cisco Packet Tracer

Project Overview

This project demonstrates the configuration and working of DHCP (Dynamic Host Configuration Protocol) in Cisco Packet Tracer.

DHCP automatically assigns IP addresses and other network configuration details to client devices.

Software Required

- Cisco Packet Tracer

How to Run the Project

1. Download the ".pkt" project file from this GitHub repository.
2. Open Cisco Packet Tracer.
3. Go to File → Open.
4. Select the downloaded ".pkt" file.
5. Check the network topology and device connections.
6. Verify the DHCP server configuration and IP address pool.
7. Select a PC and open Desktop → IP Configuration.
8. Select DHCP to obtain an IP address automatically.
9. Open Command Prompt on the PC and type "ipconfig" to check the assigned IP address.
10. Use the "ping" command to test connectivity between devices.

Expected Result

Client PCs should automatically receive IP addresses from the configured DHCP server.

Technologies Used

- Cisco Packet Tracer
- DHCP
- Computer Networking
- IP Address Configuration

Conclusion

This project demonstrates how DHCP simplifies network management by automatically assigning IP addresses to client devices.
